# Signal "Issues" regression cases

Five independent Harbor cases sourced from warning-level events for the [Issues signal](https://laminar.sh/project/a2f57110-a9ad-4178-ad14-558a8aac8283/signals/bcc13c16-f006-4412-8f69-26b503f4fb1a). No clusters exist yet. Each trial boots the real Node HTTP entry point, sends the original failing turn, and inspects the actual workspace artifacts. Reward 1 means the observed defect is absent and the requested action happened. There are no synthetic cases or controls yet. Case data uses no raw user credentials or customer records; paths and earlier messages have been normalized.

Run from the repository root with `AZURE_OPENAI_API_KEY` and `AZURE_OPENAI_ENDPOINT` exported for your Azure OpenAI resource (and optionally `AZURE_OPENAI_DEPLOYMENT` if its name differs from `GPT-6-Sol`): `npx -y lmnr-cli@latest eval run evals --remote --n-attempts 3`. The suite sets `LLM_PROVIDER=azure` and calls the real Azure deployment through the app's existing HTTP entry point. No LLM response is mocked. The default app configuration still uses Vercel AI Gateway outside this suite. Create new tasks by copying a case directory, updating `environment/case.json`, `instruction.md`, the `source_trace_id` in `task.toml`, and the deterministic checks in `image/shared/verify.py` as appropriate. Trial output lives in `/logs/agent/result.json`, and scores in `/logs/verifier/reward.txt`.

**Baseline (Azure GPT-6-Sol, three attempts each):** [evaluation](https://laminar.sh/project/a2f57110-a9ad-4178-ad14-558a8aac8283/evaluations/9d9adf48-0d40-4b39-aa15-f09bcc823d47) — budget template 0/3, budget meals 3/3, SQLite path 2/3, reminder 3/3, groceries 3/3 (11/15 total). The budget-template runs did not create the required file or report its path; the failing SQLite attempt did not create the database or give its absolute path. These are baseline failures, not harness exceptions.

**Limits:** The checked-out app uses `@lmnr-ai/lmnr` older than trajectory-file support. The eval start script sets a loopback OTEL endpoint so the app boots without sending eval spans to the production project; trial traces therefore have only the Harbor phases, not LLM/tool trajectories. These checks are artifact-based, not a replay of model outputs. The original user's complete conversation history is not present in this repository; per-case history reproduces the relevant preceding turn(s) only. The app runs in an isolated container without third-party services for these offline tasks.
